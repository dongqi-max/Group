Software requirements


Stakeholder Requirements
1. As a student, I want to organize my assignments so that I can manage my schoolwork better.
2. As a student, I want to see assignment deadlines so that I can avoid missing due dates.
3. As a student, I want reminders so that I can remember upcoming assignments.
4. As a student, I want to check off completed assignments so that I can track my progress.
5. As a student, I want to earn points or achievements so that I feel motivated to complete assignments.
6. As a student, I want the system to be simple and not distracting so that I will actually use it.
