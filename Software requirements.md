# Software requirements

1. Track product quantities in real time
2. Manage product information and categories
3. Handle stock replenishment



Stakeholder Requirements
1. As a store owner, I want to add new products so that I can manage inventory.
2. As a store owner, I want to view all products so that I can monitor stock levels.
3. As a store owner, I want to update product quantity so that inventory stays accurate.
4. As a store owner, I want to delete products so that discontinued items can be removed.
5. As a cashier, I want to view product information so that I can help customers.

Functional Requirements
1. When the user adds a product, the system shall store the product name, price, and quantity in the database.
2. When the user requests the product list, the system shall display all products from the database.
3. When the user updates product quantity, the system shall update the corresponding database record.
4. When the user deletes a product, the system shall remove the selected product from the database.
5. When invalid input is entered, the system shall display an error message.
