User stories - Student assignment tracker
- As a student, I want to add assignments with deadlines so that I can organize my schoolwork in one place.
- As a student, I want to see all upcoming assignments so that I can manage my time better.
- As a student, I want to mark assignments as completed so that I can track my progress.
- As a student, I want reminder notifications before deadlines so that I do not forget assignments.
- As a student, I want to earn points when completing assignments so that I feel motivated to finish my work.
- As a student, I want to see my progress and achievements so that I can stay encouraged and productive.
- As a student, I want the application to be simple and easy to use so that it does not interrupt my daily routine.
